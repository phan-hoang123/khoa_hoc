Nội dung học tập

  • Xây dựng website hoàn chỉnh từ Front-end đến Back-end.
  • Làm chủ React Hooks, Context API và Redux Toolkit.
  • Thiết kế Database chuẩn với MySQL và quản trị với Node.js.
  • Triển khai dự án thực tế lên AWS Cloud và Docker.
  • Tư duy giải quyết vấn đề và cấu trúc mã nguồn chuyên nghiệp.

Lộ trình khóa học

Phần 1: Giới thiệu & Cài đặt môi trường

• Tổng quan về lộ trình học tập.

• Cài đặt VS Code, Node.js, MySQL.

• Làm quen với Terminal và Git cơ bản.

Phần 2: Front-end với ReactJS chuyên sâu

• JSX, Component và Props.

• State Management & Life-cycle.

• Hooks chuyên sâu: useState, useEffect, useMemo, useCallback.

• Quản lý Global State với Redux Toolkit.

Phần 3: Back-end với Node.js & Express

• Khởi tạo Server và Routing.

• Middleware & Error Handling.

• Kết nối MySQL với Sequelize/Knex.

• Xây dựng hệ thống xác thực (Auth) với JWT.

Phần 4: Đồ án cuối khóa & Triển khai

• Xây dựng hệ thống Thương mại điện tử Fullstack.

• Tối ưu hóa hiệu năng (Performance).

• Deploy lên AWS Cloud sử dụng Docker.
